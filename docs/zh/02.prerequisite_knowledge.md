# 前置知识

在使用 Vision SDK 进行开发之前，建议您先了解以下基本概念和基础知识。

## 昇腾AI基础概念

| 概念 | 说明 | 了解更多 |
|------|------|---------|
| 昇腾AI处理器 | 华为自研的AI处理器，提供高效的AI推理和训练能力 | [昇腾社区](https://www.hiascend.com/) |
| CANN | 华为AI计算框架，提供昇腾AI处理器的算子库和运行时 | [CANN 文档](https://www.hiascend.com/document?tag=community) |
| NPU | 神经网络处理单元，昇腾AI处理器的核心计算单元 | 相关文档 |
| Davinci | 昇腾AI处理器的架构名称 | 相关文档 |
| DVPP | 数字视觉预处理模块，提供图像/视频的硬件加速处理能力 | 相关文档 |
| AIPP | AI预处理模块，在模型推理前对输入数据进行预处理 | 相关文档 |
| OM模型 | 经过ATC工具转换后的离线模型，可在昇腾AI处理器上直接加载推理 | [ATC工具说明](https://www.hiascend.com/document) |

- Atlas 300V Pro 视频解析卡

支持 Linux 发行版，包括但不限于：

- Ubuntu 18.04/20.04/22.04/24.04
- CentOS 7.6
- EulerOS 2.11/2.12/2.15
- openEuler 22.03/24.03
- KylinOS V10/V11
- 更多请参见 [支持的操作系统列表](./01.introduction.md#支持的硬件和操作系统)

### 开发语言

Vision SDK 支持以下开发语言：

- **C++**：提供完整的 C++ API，建议有 C++ 开发经验的用户使用
- **Python**：提供 Python API 封装，适合快速原型开发

### 开发工具

| 工具 | 说明 | 获取方式 |
|------|------|---------|
| CMake | C++ 项目构建工具（不低于 3.5.2） | 包管理工具安装 |
| GCC | C++ 编译器（推荐 7.3.0） | 源码编译或包管理安装 |
| Python 3 | Python 运行时（3.9/3.10/3.11/3.12） | 源码编译安装 |
| Docker | 容器环境（容器部署方式需要） | [Docker 官网](https://docs.docker.com/) |

## 开发方式

Vision SDK 提供两种开发方式，您可以根据业务需求选择：

### 1. API 接口开发方式

通过调用 Vision SDK 提供的 API 接口进行应用开发，适合有固定开发流程的用户。

- **C++ API**：提供完整的初始化、媒体数据处理、模型推理、后处理等接口
- **Python API**：对 C++ API 的 Python 封装，接口更简洁

> 参考文档：[API接口参考（C++）](./api/cpp/README.md) | [API接口参考（Python）](./api/python/README.md)

### 2. 流程编排开发方式

采用模块化设计，将功能单元封装为独立插件，通过插件串接快速构建业务。

> 参考文档：[流程编排开发](./03.quick_start.md#23-流程编排开发方式)

## 基本工作流程

Vision SDK 的典型使用流程如下：

1. **环境准备**：安装昇腾驱动、CANN 和 Vision SDK
2. **模型准备**：获取或转换 OM 模型
3. **应用开发**：选择 API 或流程编排方式进行开发
4. **部署运行**：在目标硬件上部署运行
