# Welcome to Vision SDK

<div style="text-align: center; margin: 0.5rem 0 0.3rem 0; font-family: 'Avenir Next', 'Avenir', 'Century Gothic', 'Segoe UI', sans-serif;">
  <span style="font-size: 4.5rem; font-weight: 300; letter-spacing: 0.02em;">Vision SDK</span>
</div>

Vision SDK is the SDK in MindSDK for visual analysis of images and videos. It provides basic intelligent analysis capabilities for videos and images as well as a programming framework. This docs repository provides the related guidance documentation for Vision SDK.
