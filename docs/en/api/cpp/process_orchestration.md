### MxStreamManager

#### Class Description

This class manages inference streams.

**Common Parameters**

|Parameter|Data Type|Description|
|--|--|--|
|rotateTimeFlag_|std::atomic\<bool>|Time-based log rotation switch. The default value is `true`.|
|rotateNumberFlag_|std::atomic\<bool>|Count-based log rotation switch. The default value is `true`.|
|dynamicFlag_|std::atomic\<bool>|Configuration-file-based log rotation switch. The default value is `true`.|
|performanceStatisticsFlag_|std::atomic\<bool>|Performance statistics log switch. The default value is `true`.|

**Supported Models**

Atlas 200I/500 A2 inference products

Atlas inference products

#### CreateMultipleStreams

**Function Description**

Creates multiple Streams from the specified configuration. Use this interface together with `DestroyAllStreams`.

Do not call `CreateMultipleStreams` and `DestroyAllStreams` repeatedly in one process.

**Function Prototype**

#### GetPacket

**Function Description**

Template function. Retrieves data from the specified element in the specified Stream. The function throws an exception if memory is insufficient. It does not support multithreaded concurrency.

- If the specified element is an **appsink** plugin, the received data is `Packet<std::shared_ptr<MxstBufferOutput>>`.
- If you specify another element, the corresponding metadata is returned. Supported types are `Packet<std::shared_ptr<**MxVisionList**>>`, `Packet<std::shared_ptr<**MxTensorPackageList**>>`, `Packet<std::shared_ptr<**MxObjectList**>>`, `Packet<std::shared_ptr<**MxImageMaskList**>>`, `Packet<std::shared_ptr<**MxClassList**>>`, `Packet<std::shared_ptr<**MxPoseList**>>`, `Packet<std::shared_ptr<**MxTextObjectList**>>`, and `Packet<std::shared_ptr<**MxTextsInfoList**>>`.

**Function Prototype**

#### GetProtobuf

**Function Description**

Retrieves the protobuf result from the output element on the Stream for `appsink`. `appsink` blocks while fetching data from the queue. If the queue is empty, it blocks. It does not support multithreaded concurrency.

This interface must be used together with [SendProtobuf](#sendprotobuf). Otherwise, data may accumulate.

**Function Prototype**

```cpp
std::vector<MxstProtobufOut> MxStreamManager::GetProtobuf(const std::string& streamName, int outPluginId, const std::vector<std::string>& keyVec);
```

**Parameters**

|Parameter|Input/Output|Description|
|--|--|--|
|streamName|Input|Stream name.|
|outPluginId|Input|Target output plugin ID, that is, the ID of the `appsrc` element.|
|keyVec|Input|Keys of the protobuf data to send and retrieve. The corresponding protobuf result memory is managed by smart pointers and does not need to be released.|

**Returns**

|Data Type|Description|
|--|--|
|std::vector\<MxstProtobufOut>|Inference service output data list. See `MxstProtobufOut`.|

#### SendData

**Function Description**

Sends data to the input element (`appsrc`) on the specified Stream. Blocking. Does not support multithreaded concurrency.

This interface must be used together with [GetResult](#getresult). Otherwise, data may accumulate.

**Function Prototype**

```cpp
APP_ERROR MxStreamManager::SendData(const std::string& streamName, int inPluginId, MxstDataInput& dataBuffer);
```

```cpp
APP_ERROR MxStreamManager::SendData(const std::string& streamName, const std::string& elementName, MxstDataInput& dataBuffer);
```

```cpp
APP_ERROR MxStreamManager::SendData(const std::string& streamName, const std::string& elementName, std::vector<MxstMetadataInput>& metadataVec, MxstBufferInput& bufferInput);
```

**Parameters**

|Parameter|Input/Output|Description|
|--|--|--|
|streamName|Input|Stream name.|
|inPluginId|Input|Target input plugin ID, that is, the ID of the `appsrc` element. (`appsrc` ID indicates which `appsrc` element it is.)|
|elementName|Input|Input plugin name. Only `appsrc` is supported as the input plugin.|
|dataBuffer|Input|Data to be sent. `MxstDataInput.dataBuffer.dataSize` must be equal to the memory size of the data to be sent and fall within [1, 4294967296]. `dataBuffer.dataPtr` must be deleted.|
|metadataVec|Input|For the protobuf data list to send, see `MxstMetadataInput`.|
|bufferInput|Input|Data to be sent. The data type is `MxstBufferInput`. `bufferInput.dataSize` must be equal to the memory size of the data to be sent and fall within [1, 4294967296]. `bufferInput.dataPtr` must be deleted.|

**Returns**

|Data Type|Description|
|--|--|
|APP_ERROR|Error code returned by the program. See [APP_ERROR Description](./basic_component_layer.md#app_error-description).|
