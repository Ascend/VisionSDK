### `MxStreamManager`<a name="ZH-CN_TOPIC_0000001860120973"></a>

#### Class Description<a name="ZH-CN_TOPIC_0000001813201232"></a>

This class manages inference streams.

**Public Parameters<a name="section8248123635110"></a>**

|Parameter|Data Type|Description|
|--|--|--|
|rotateTimeFlag_|`std::atomic<bool>`|Switch for time-based log dump. The default value is `true`.|
|rotateNumberFlag_|`std::atomic<bool>`|Switch for count-based log dump. The default value is `true`.|
|dynamicFlag_|`std::atomic<bool>`|Switch for log dump based on the configuration file. The default value is `true`.|

#### `GetPacket`<a name="ZH-CN_TOPIC_0000001813360564"></a>

**Function<a name="section155284363917"></a>**

Template function that requests data from the specified element in the specified service stream. An exception is thrown inside the function when the memory is insufficient. Multi-thread concurrency is not supported.

- If the specified element is an **appsink** plugin, the received data is Packet<std::shared\_ptr<MxstBufferOutput\>\>.
- If another element is specified, the corresponding Meta data is obtained. The supported types are Packet<std::shared\_ptr<**MxVisionList**\>\>, Packet<std::shared\_ptr<**MxTensorPackageList**\>\>, Packet<std::shared\_ptr<**MxObjectList**\>\>, Packet<std::shared\_ptr<**MxImageMaskList**\>\>, Packet<std::shared\_ptr<**MxClassList**\>\>, Packet<std::shared_ptr<**MxPoseList**\>\>, Packet<std::shared\_ptr<**MxTextObjectList**\>\>, and Packet<std::shared\_ptr<**MxTextsInfoList**\>\>.
