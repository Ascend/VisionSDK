### Overview<a name="ZH-CN_TOPIC_0000001852384876"></a>

This section shows only the attributes of the data classes. It does not show the related functions in full.

The data classes in this section are generated by SWIG. Some data types show only part of the service-related interfaces. For details, see `base.py`, `post.py`, `log.py`, and `dvpp.py`. Note that the SWIG framework automatically generates internal classes and functions such as `SwigPyIterator`. You are advised not to use them.
