# Log Output

## log Function Set

|Function Name|Parameter Type|Description|
|--|--|--|
|debug(str)|String|Prints debug-level logs.|
|info(str)|String|Prints info-level logs.|
|warning(str)|String|Prints warning-level logs.|
|error(str)|String|Prints error-level logs.|
|fatal(str)|String|Prints fatal-level logs.|
|init()|-|Initializes logging.|

**Supported Models**

Atlas 200I/500 A2 inference products.

Atlas inference series products.
